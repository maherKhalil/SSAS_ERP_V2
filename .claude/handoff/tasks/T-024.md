## Goal

Your `NEEDS-DECISION` is ruled, and your observation is the answer — with more behind it than you claimed.

**`ADR-021` stays `Proposed`.** It states its own terms at line 37: it moves to Accepted when a
customer-hosted deployment is actually contracted. None is. It fails its own test, and `DEC-L-020`
exists to stop an argument from use overriding a document's own terms. Moving it was never available.

So the citation moves instead. You noted the reasoning `REQ-SUB-0005` relies on follows from `ADR-017`
rather than from customer-managed hosting. I checked, and it derives completely from `ADR-017` alone:
`:162` places subscription/plan metadata in the **Platform** database, and `:171` rules that login,
token refresh, platform authority evaluation and tenant membership resolution **must not** depend on
the tenant server being reachable, with `:376`-`:378` requiring a controlled unavailability result
rather than a fallback. Both facts sit in an **Accepted** ADR.

## Acceptance criteria

- [ ] **`REQ-SUB-0005`'s Authority column cites `ADR-017`**, not `ADR-021:207`. The derivation is the
      pair — subscription data is Platform-database data, and Platform-plane operation does not depend
      on the tenant server — so cite both line references rather than one.
- [ ] **`DEC-SUB-0004` is re-pointed on the same basis**, since it is built on the same passage.
- [ ] **`decisions-ratified.md`'s `OD-SUB-0004` entry records the re-point**, because that ruling
      excluded a tenant-database projection *because of* the outage constraint. The ruling does not
      change; its authority does, and a ratified file must not silently acquire a different basis.
- [ ] **`ADR-021:207` may remain as a cross-reference only where it is labelled** as an
      implementation-deferred ADR that does not yet bind. If keeping it adds nothing at a given site,
      drop it — a reference to a deferred decision is a future reader's trap, as `ADR-028` was.
- [ ] **`decisions-open.md:487`**, which says `ADR-021` constrains this package, is corrected to match.
- [ ] `py scripts/trace-check.py FP-014-subscription` still **GREEN, 0 unruled**, run with every other
      package present. `git diff --stat` shows **at most four files**, all under
      `docs/17-features/FP-014-subscription/`.
