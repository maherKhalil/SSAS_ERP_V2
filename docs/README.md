# SSAS ERP V2 Documentation

## Purpose

This repository contains the complete functional and technical specification for SSAS ERP V2.

The documentation is the single source of truth for:

- Product Management
- Business Analysis
- Solution Architecture
- Software Development
- Quality Assurance
- DevOps
- AI-assisted Development (Codex)

The implementation must always follow the documentation.

Whenever requirements change, the documentation shall be updated before implementation.
