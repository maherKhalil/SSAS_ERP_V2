## Part C — a prose capability name is a legitimate anchor

FP-011's coverage rows read `| Administer grants no functional permission | ADR-025 d8 | AC-GL-0017 |
TS-GL-0022 |`. Criteria and scenario present; **first cell a capability name carrying no identifier**,
which the T-062 parser could not anchor. FP-002, FP-005 and FP-006 lead their chain tables the same
way.

**A row carrying both an `AC-` and a `TS-` is now a chain row regardless of what leads it.**

### The contiguity was the finding, and it was not about coverage

`AC-GL-0017`..`0021` were **consecutive**, which looked systematic and was — **the systematic thing was
the authoring order of the criteria file.** They were written as a block, so they landed on adjacent
matrix rows, so one parser blind spot took all five at once.

**Recorded because the next contiguous block anyone sees will look exactly as alarming.** A run of
consecutive identifiers is evidence that one cause touched all of them. **It is not evidence that the
cause is in the corpus** — here it was in the instrument, and the block was an artefact of how the
document was typed.

## Part B — ownership declared, the heuristic deleted

**Deleted, not supplemented.** A module used to be "owned" by whichever package held at least a
quarter of the identifiers carrying its token. **`DOC` therefore belonged to FP-009 because FP-009 has
96 and FP-010 has 25** — so FP-010's own scenarios read as somebody else's, and FP-009's citation of
them read as an internal orphan.

**A majority count deciding who owns a namespace is an answer over a domain nobody established.**
`SPACE_OWNERS` names them; `DOC` names two; a space in no entry **fails**.

Three things followed that the ruling did not anticipate, and all three are now in the code with their
reasons:

**1. A citation is not a definition.** The first version failed **seventeen** master-register spaces —
`BR-PLT-0001`, `REQ-HR-0100` — because packages cite them inside their own home files. The check now
consults a **master-register module set built separately from the global index.**

**2. A shared space resolves against its co-owners.** FP-009 citing a scenario FP-010 defines is an
external reference, not an orphan, *even though the space is "mine"* — because it is also FP-010's.

**3. Contiguity is not assertable per package for a co-owned space.** FP-009 holds the lower `DOC`
numbers and FP-010 the upper ones, by the same recorded agreement that neither reallocates the
other's. **Each package alone looks full of holes; together they are contiguous.** Asserting it per
package failed both packages for honouring the agreement — so it is reported, exactly as `BRULE-`
contiguity is, and for the same reason: **a rule whose domain was never established is reported, not
asserted.**

`carried-analysis.md` is a declared home for `TS-` **in FP-010 only**, never added globally.

**The first version did not fire, and the plant is the only reason I know that.** It tested the module
against the **global index**, which absorbs every package's own home files — so a planted identifier is
"known" the instant it is planted. **The check was structurally incapable of failing**, and it read as
a pass on a green package.

That is `DEC-L-059` catching an instrument rather than a fixture: **prove the plant landed, and prove
the check can fail.**
