# ⚠ 2. NEITHER GUARD CAN EXPRESS "A PERIOD WHOSE RUN WAS REVERSED", AND THE REASON IS T-110's FINDING

**Reversal is not recorded on the run.** `ReversePayrollRunCommandHandler` leaves it `Posted` and writes
nothing, deliberately — *"Marking it 'reversed' would be a claim the ledger already makes better."*

**So in the `PayrollRuns` table these two are byte-identical:**

```
a period whose run was reversed and needs a correction     -> must allow a second run
a period with a live posted run                            -> must refuse a second run
```

**The fact that separates them exists only in GL, as the reversing entry's existence.**

**This is not a query I have failed to write. It is a distinction the data does not carry** — and you told
me to say so rather than widen the guard. **Widening it to "allow a second run when one exists" opens
exactly the two-live-runs case the guard exists to prevent, and nothing left in the schema would catch it.**

# THE THREE SHAPES, AND ONLY ONE KEEPS THE DATABASE AS THE AUTHORITY

**1. Record reversal on the run.** A `ReversedUtc` or `ReversedByJournalEntryId`, written by the reversal
handler. Uniqueness becomes a **filtered** unique index — one *unreversed* run per period — **and the
database stays the authority.**

- **Against:** it contradicts the handler's stated reason for writing nothing.
- **For, and I think it answers that:** the reason was *do not duplicate GL's truth for GL's purposes.*
  **Payroll needs the fact for its own uniqueness rule, which is a different purpose** — and a filtered
  index cannot read another module's table.

**2. Ask GL at create time.** A contract member on `IJournalPoster`. **Costs a cross-module read on the
create path — and it cannot be enforced by a constraint at all**, so uniqueness becomes application-only and
the authority the comment relies on is gone.

**3. A run sequence per period.** Unique on `(Tenant, Company, Period, Sequence)`, plus "at most one live".
**"Live" still requires knowing which runs are reversed, so it collapses into 1 or 2** rather than being a
third option.

**My reading: (1).** It is the only one where the two guards can still say the same thing, and the objection
to it turns out to be about a different purpose than the one T-112 has.
