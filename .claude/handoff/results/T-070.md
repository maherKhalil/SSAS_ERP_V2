## Proved across three states before it was trusted

The block was **extracted verbatim from `scripts/gate.sh` by line range** — 63 lines, the shipped text
rather than a paraphrase — and run against a fresh worktree:

```
A  a genuinely clean tree      [TREE: 0 modified, 0 untracked; HEAD matches origin/ClaudeBranch]
B  one modified, one stray     modified:  README.md
                               untracked: .claude/handoff/T-070-stray.md
C  detached HEAD, 2 back       [TREE: 1 modified, 1 untracked; HEAD is 0 ahead / 4 behind origin/ClaudeBranch]
```

**Case A is the point of the exercise.** A report that only ever prints when something is wrong is the
check that cannot fail — found one task ago, in a check I wrote. **The clean case is a result and it is
printed as one**, so its absence means the report did not run rather than that nothing was found.

**Case B names a `.claude/` file deliberately.** The incident that prompted this rule was
documentation; excluding that directory would have made the exact case invisible.

## What it does not do

**It never fails the gate.** A dirty tree is the normal state of a window mid-task, and a gate that
refused one would be disabled by its user inside a day — which is the failure this file has spent a
week removing. **The defect was never the dirty tree. It was a verdict that did not say what it
measured.**

**It attributes nothing.** Two windows, one tree, and no reliable way to tell whose edit is whose.
Naming the files lets the reader conclude; **asserting an owner would be a guard claiming a cause it
cannot know**, which is the defect recorded eight times on this board and the reason every message in
this file states a question.

## Why the rule needed a structural half

`DEC-L-065` as a procedure is *"re-run the gate on the thing being merged"* — a rule someone forgets on
the first busy evening. **This makes forgetting visible rather than fatal:** the verdict carries the
tree it measured, so a green that was bought by another window's open files can be recognised
afterwards by anyone reading the log.

**It is affordable only because of `T-056`.** A second worktree was unsafe this morning — two gates
would have reaped each other's catalogs — and the instance lock is what makes re-running on a clean
tree a thing a person can actually do. **The guard built this morning is what makes the rule prompted
this evening practical.**
