new component; there is no narrower door.

**Guard 2 — narrow, and narrow because it is exactly right.** An employee dimension has two doors: the

## The messages state the question, never the cause

They fail on **any** change to those shapes. So each says *this computation assumes full-time, the
model may now express otherwise, here is what to check* — never *you added employment type*. **A guard
asserting a cause it cannot know is an instrument reporting on a domain nobody established, committed
in prose.**

Each carries its own consequence, and guard 2's is the one a reader will not infer: **every leave
record already written keeps its wrong count forever, because the figure is stored and never
recomputed — correctly — so a fix does not reach backwards.**

## A defect in yesterday's wiring, found by its own reporting

The first gate run printed:

```
--- trace-check: did not complete (exit 2)
C:\c\Users\...\scripts\trace-check.py: [Errno 2] No such file or directory
```

**`py` is a native Windows launcher and cannot open an MSYS path.** `$ROOT` is `/c/Users/...`, which
Python resolves against a `C:` drive with a `c` folder under it. **`DEC-L-056` from the other
direction**: that rule is about a variable that *disables* path conversion; this is a shell-native path
handed to a Windows program with *no* conversion. Same class, opposite cause.

**Fixed by using relative paths** — the gate `cd`s to `$ROOT`, so they are correct and immune.

**It was found in seconds because the block reports when it does not complete.** Without that line the
traceability check would have been silently absent from every gate run, which is precisely the failure
it was wired in to end. **The rule caught its own author's mistake on the first live run.**
