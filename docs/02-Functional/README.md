# Purpose

The Functional Specification describes how every feature of SSAS ERP behaves.

Unlike the Master Product Specification, which defines **what** the product shall do, the Functional Specification defines **how** users interact with the system.

This document is the primary implementation reference for developers and AI-assisted coding tools.

---

# Scope

The Functional Specification covers:

- Business workflows
- User interactions
- Screen behavior
- Field definitions
- Business validations
- Permissions
- Audit requirements
- Notifications
- Reports
- API references
- Database references
