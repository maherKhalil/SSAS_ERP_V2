## Where the completeness guard lives, and why not in `Architecture.Tests`

The spec put it in `Architecture.Tests`. **It is split**, on the `AppendOnlyEnforcementArchitectureTests`
precedent:

- **`Architecture.Tests`** — surface: four keys, one per module assembly, unique and non-empty; no key
  on the platform plane; exactly one `ITenantModuleEntitlement` implementation.
- **`API.Tests`** — completeness: boots the real host, reads the mapped endpoint inventory, and asserts
  every module-owned endpoint is gated **with its own key**, and no platform-plane endpoint is.

Reflection cannot read a method body, so nothing in `Architecture.Tests` can see whether a route group
actually called `RequireModule`. The endpoint inventory can, and only the booted host has it. **The
guard that fires when a module route is added ungated is therefore the `API.Tests` one**, which is what
criterion 4 measures.

**Ownership resolves by the handler's declaring assembly, not the route prefix.** Prefix matching would
reintroduce the divergent notion of module `OD-SUB-0005` excluded, and would be wrong in a way that is
hard to see: HR mounts seven prefixes and any one of them reads like a module boundary.

## The 403, and why the tenant was the wrong thing to vary

You offered the out — say it cannot be tested honestly. **The untestable thing was not the assertion,
it was the variable.** With one resolver granting everything, varying the *tenant* has no case: no
tenant lacks a module. So the test varies the **resolver**, on a two-route host built in the test file.

Three assertions, all honest:
- **Refused → 403, and the handler never runs.** A gate that refused *after* the work would still have
  done the work.
- **Entitled → passes through unchanged.** This is what makes the transitional resolver safe to ship:
  mounting the seam changes no observable behaviour.
- **Ungated route → entitlement is never consulted at all.** Structurally stronger than the
  platform-plane exemption asked for, because it holds whatever the resolver would have answered.

The file states it does not claim any real tenant is refused, and names the end-to-end version as
arriving with the schema.
