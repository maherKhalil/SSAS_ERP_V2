# ⚠ THE PATTERN ALREADY EXISTED IN THIS SUITE AND NEITHER WINDOW KNEW

`RepositoryPathPortabilityTests.No_architecture_test_parses_a_project_reference_with_the_framework_path_helper`
scans `tests/Architecture.Tests` — and it already does **both** things the citation guard had to learn:

```csharp
.Where(path => !string.Equals(Path.GetFileName(path), "RepositoryPaths.cs", ...) &&
               !string.Equals(Path.GetFileName(path), "RepositoryPathPortabilityTests.cs", ...))
```

and it strips comments first, with the reason stated:

> *"Comments are stripped: these files EXPLAIN the banned call, and a scan that read the prose would fail
> because someone documented the rule it enforces."*

**Self-exclusion and comment-stripping, both already written down, in the one other guard that scans its own
tree.** T-182 rediscovered both the hard way — one by suspicion, one by a failing test.

**The transferable point is not the technique, it is where to look for it: when a guard's subject exists in
both trees, someone has probably already hit this.** A search for prior art in the suite would have been
cheaper than either discovery.
