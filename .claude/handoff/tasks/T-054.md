# T-054 — Wire both modules up, once

**Serialized. One window. Runs only after T-052 and T-053 have both merged.**

Everything T-052 and T-053 were forbidden to touch happens here, in one pass, with the true final
module count known — which is the entire reason it was deferred.

## The work

1. **Model contributors.** An `IModelContributor` per module (`ADR-012`), plus entity
   configurations for both. Note `TenantDbContext.OnModelCreating`: contributors run **before**
   `base.OnModelCreating` so contributed entities are visible to the global tenant query filter and
   the restricted delete behaviour. An entity added afterwards is unfiltered — the silent
   cross-tenant leak the filter exists to prevent.
2. **`.API` and `.Infrastructure` projects** for both modules, plus a `*ModuleEnablement`
   descriptor each.
3. **One migration covering both modules.** Not two. Scaffold it with the procedure T-050 wrote
   into `ADR-018` — the migration tool as `--startup-project`. **Recognition test, from that same
   section: any tenant migration whose `Up` drops a module table was scaffolded wrongly.** Check
   yours before committing; thirteen committed migrations pass that test and yours must too.
4. **The counted assertions, updated once to `6`:**
   - `tests/Architecture.Tests/ModuleEnablementArchitectureTests.cs` — the named assembly array and
     `Assert.Equal(4, keys.Count)`. It is a named list rather than a scan on purpose: the file says
     a scan *"would pass vacuously if it ever returned nothing."* Keep it named.
   - `TrialSubscription`'s module list, asserted as an **exact set** by
     `The_trials_module_list_is_exactly_the_set_the_product_declares`. Its comment states the drift
     it catches: a new module absent from every trial, so every new tenant evaluates it and finds
     nothing.
5. **Host registration** — `Program.cs`, `.csproj` references, `ComposedTenantDbContextFactory`.
   Every mounted route group must be gated: `BR-PLT-0008` is enforced now, so an ungated route
   fails the guard rather than shipping.

## Done when

- Zero-warning build; **all** gate suites green, including `Integration.Tests` — persistence,
  migration and EF configuration are all touched here, so `DEC-L-008` condition 3 applies.
- The migration's `Up` creates tables and drops none.
- Both modules are gateable, both appear in the trial plan, and the guard asserts `6`.
- Any port mismatch reported by T-052 or T-053 against `IJournalPoster` is either resolved here or
  carried forward as a named finding — not quietly dropped because the build went green.
