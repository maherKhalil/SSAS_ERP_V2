# ⚠ THE STRONGEST CHECK WAS AVAILABLE ALL DAY AND NEITHER OF US REACHED FOR IT

**C# is statically compiled. Deleting a referenced member is a compile error.**

The solution builds with **0 errors and 0 warnings** and the full gate passes at 3,008 tests. **That is a proof, not a sample**, that no code referenced any of the six by name — stronger than every walk we built today and immune to all six of the enumeration failures, because the compiler does not match patterns, it resolves symbols.

**The risk you named — a factory-returned code invoked as `CompensationErrors.NoneInForce(date)` inside a conditional — is exactly what the compiler catches and what a grep would miss.** It is the one shape where the cheap instrument beats the careful one outright.
