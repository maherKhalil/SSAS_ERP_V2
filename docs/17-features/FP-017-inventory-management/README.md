# FP-017 Inventory Management (Supply Chain)

## Scope
Manages central warehouses, stock levels, item master data, stock transfers, and adjustments.
Crucial for integrating with the HIS Pharmacy and Laboratory modules to manage consumable medical stock.

## Key Entities
- Warehouse / Location
- Item (Medical, Consumable, General)
- Stock Transaction (In, Out, Transfer, Adjustment)
- Stock Level
