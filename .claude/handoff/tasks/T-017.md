# T-017 — Two one-line corrections to documents whose summary text misled a reader

- **Branch:** `agent/T-017-summary-corrections` — branch from `main`
- **Module:** Docs / tooling
- **Issued:** 2026-08-25
- **Depends on:** T-020 merge

## Goal

Two unrelated files, one theme: in each, a **summary line was wrong or unannotated while the body was
right**, and in each the summary is what a tool reads and a skimming human checks. One of them
produced a false High finding that survived nine tasks. Folding T-019 into this task; they are the
same defect twice.

## Acceptance criteria

- [ ] **`scripts/gate.sh`** — the healthy-memory band in note 7a is corrected. It currently records
      1,200–1,500 MB free as normal working depth for a LEAN Integration leg, generalised from T-014's
      two legs. **T-015 measured `min_free` 551 MB (Debug) and 580 MB (Release), both legs green.**
      Record the observed range honestly and state the point plainly: **the number is not the signal —
      the signature is, and the signature is a leg dying with no TRX.**
- [ ] The note says the band is **observed, not a threshold**, and that a low mid-leg reading is not a
      reason to abort a run or to raise the floor. It has now caused one false alarm (architect, T-014,
      1,946 MB flagged as a risk when both legs of that very run went lower and finished green).
- [ ] **`docs/17-features/FP-010-hr-employee-documents/README.md`** — the `depends_on: ADR-028`
      front-matter entry is annotated as a **reservation**, so it no longer reads as a dependency on a
      missing file. The body explains it three times; the front-matter is what misled.
- [ ] The annotation names where the reservation is recorded — `DEC-DOC-0010` and `OD-DOC-009` — so a
      reader can reach the reasoning in one hop rather than three.
- [ ] `git diff main...agent/T-017-summary-corrections --stat` shows **exactly two files**.

## Files in scope

- `scripts/gate.sh` — note 7a only
- `docs/17-features/FP-010-hr-employee-documents/README.md` — front-matter only

## Out of scope

- Every other note in `gate.sh`, and its exit codes, defaults and preconditions. T-016 settled those.
- The body of FP-010, and every other feature package's front-matter. **If another package carries a
  `depends_on` on something reserved or deferred, report it** — do not sweep.
- **Do not change the memory floor itself.** 2,048 MB LEAN stands. This corrects the *documentation of
  observed depth*, which is a different thing, and conflating them is what caused the false alarm.
- Any file under `src/` or `tests/`.

## Design constraints

- **Do not run `gate.sh` to verify this.** It is a comment change; a 69-minute run proves nothing about
  it, and `DEC-L-002` means no gate is required. Read the edited note back.
- Keep note 7a's existing voice — the header is written as instruction to a person, and the
  measured-figures corrections T-016 made are the model.
- The FP-010 annotation is **one entry**, not a rewrite. Front-matter is a machine surface; keep it terse.

## Tests required

**None** — `DEC-L-002`. Verification is the `--stat` assertion plus the edited text read back.
