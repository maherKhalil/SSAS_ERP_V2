## Design constraints

- **Extend, do not restructure.** The existing six checks and their output format are proven and are
  the reason this script is trusted. The new check is an addition beside them.
- **The script must stay runnable with no dependencies beyond the standard library**, as it is today.
  Nothing in this repository installs Python packages for tooling.
- **Report, never mutate.** It reads and prints. It must not edit a document, write a fix, or create
  a file.
- Where the check cannot decide — an identifier that looks like a reference but might be prose —
  prefer reporting it as UNRESOLVED over silently passing. A checker that under-reports is worse than
  one that occasionally asks a human to look, because it is trusted at exactly the moment it is wrong.
