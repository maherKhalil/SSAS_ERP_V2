## Tokens, not substrings, and the specimen is `Company`

**`"Company".Contains("pan")` is true** — c-o-m-**pan**-y. A substring matcher flags every `CompanyId`,
`CompanyName` and `NormalizedCompanyCode` in the repository, and **the only repair that greens it is
dropping `pan` — deleting the term that catches the actual primary account number.**

That is the rule being narrowed to pass, and **it arrives looking like ordinary maintenance.** The
identifier is therefore split into words and the short unambiguous terms matched as whole tokens.

**The same reasoning inverted for `expiry`:** a **card** expiry is cardholder data and a **token**
expiry is not, and this repository is full of the second — refresh tokens, sessions, action tokens,
backup retention. `expiry` fires only when qualified by `card`, and `ExpiresUtc`,
`RefreshTokenExpiresUtc` and `TokenExpiry` are in the negative-control set so the distinction is
**tested rather than commented**.

## `DEC-L-043` for a guard that passes first time

**The specific way this one could be hollow: it reads a DIRECTORY.** `GetReferencedAssemblies()`
reports what the compiler kept rather than what the project references — an assembly referenced and
never touched by test code is pruned and would silently leave the scan — so the output folder is the
honest inventory. But a build-layout change, a renamed folder or an over-broad filter would leave it
**scanning nothing and passing silently forever**, indistinguishable from working.

Ruled out two ways:

1. **Floors asserted** — 25 assemblies, 1000 types, 5000 members, well under the measured 33 / 3420 /
   25 339. Zero cannot pass.
2. **The counts and the full assembly list are emitted, not only asserted.** Floors catch the total
   collapse; **emitting the list catches the partial one**, and lets a reader confirm the `.Contracts`
   assemblies are in scope **without having to break the test to find out.**

## What the guard cannot see, stated in the file at length

**It cannot see capability in general, and no reflection-based guard can.** `string Notes` is capable
of holding a primary account number; so is every free-text field in the product. Flagging them would
flag thousands of members and the guard would be switched off within a week.

`ADR-029`'s risks section is **quoted rather than paraphrased**, so the next reader compares the guard
against the ADR's own words rather than against a summary of them — and the conclusion is stated
plainly: **this guard covers the case the ADR says nobody will commit, and not the case the ADR says
will actually happen.**

Also named as unseen: a `Dictionary<string, string>` or JSON blob (capable, unnameable); a value
passing through a parameter without being stored; and a provider callback logged verbatim, which is
`ADR-029`'s second named edge.
