# ⚠ I DID NOT ADD A TEST, AND THE REASON IS THE RULE

`tests/` was in scope and I left it empty. **Every test I could write here is one of the two shapes this
loop has learned to refuse:**

- **A test asserting `--citers` exists** is a green that proves nothing — `DEC-L-070`. It passes whether or
  not the advisory works.
- **A test asserting "it never returns non-zero"** would have to either shell out to `py` — which the suite
  does nowhere, and a test that cannot run reliably is worse than none — or walk the source for `return`
  statements, which is **`DEC-L-078` exactly: a source-text walk that under-resolves reports a smaller
  closure and every miss looks like a clean stop.**

**The four plants are the evidence, and they test the behaviour rather than the shape.** Saying so because
an empty `tests/` in a gated task should be a decision on the record, not an omission.
